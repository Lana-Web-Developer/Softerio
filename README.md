## Использованные технологии

Проект реализован с использованием современных инструментов фронтенд-разработки:

-   React + TypeScript — основа приложения.
-   Vite — быстрая сборка проекта.
-   Tailwind CSS — современный дизайн.
-   React-Hook-Form + Zod — работа с формой.
-   React Router Dom — навигация по страницам.
-   Слайдер Swiper — интерактивные слайдеры для блоков услуг.
-   Mobile-first подход — отличное отображение на любых устройствах.
